# Интеграция v0.3 — Mini App + тонкий клиент + служебный чат

## Роли

| Кто | Что видит |
|-----|-----------|
| Пользователь | Бот (тонкий клиент) и/или Mini App, личные уведомления |
| Служебный чат | Только бот (+ вы как админ). Хроника заявок |
| Бот | Пишет/редактирует хронику, ведёт диалоги, шлёт notify |

## Тонкий клиент

Пользователь может не открывать Mini App:

- «Мне нужно» / «Я могу» / «Мои заявки» — постоянная reply-клавиатура
- Геолокация — нативная кнопка `request_location`
- Категории и радиусы — inline-кнопки
- TAKE / COMPLETE — callback-кнопки на карточках

## Настройка SERVICE_CHAT_ID

1. Создать закрытую группу.  
2. Добавить бота админом.  
3. Написать любое сообщение в группу.  
4. `https://api.telegram.org/bot<TOKEN>/getUpdates` → `chat.id`.  
5. Прописать в `.env`: `SERVICE_CHAT_ID=-100…`

Пользователей продукта в эту группу **не** добавлять.

## GPS

- При создании заявки координаты пишутся в служебное сообщение и в индекс.  
- Поиск «Я могу» (бот и Mini App) фильтрует по GPS пользователя (haversine).  
- После TAKE бот **редактирует** сообщение: блок `📍 …` убирается.  
- В API nearby и в сообщениях пользователям координаты **не** отдаются.
