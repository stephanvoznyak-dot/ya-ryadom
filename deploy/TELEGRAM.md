# Telegram

1. Создать бота у @BotFather, получить токен.
2. Включить Menu Button / Web App: URL Mini App.
3. Создать закрытую группу (служебный чат), добавить бота как администратора.
4. Узнать chat.id группы (например, через getUpdates после сообщения в группе).
5. Прописать SERVICE_CHAT_ID и TELEGRAM_BOT_TOKEN в `.env`.

Пользователей приложения в служебную группу не добавлять.
